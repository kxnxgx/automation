# 実装計画 (implementation_plan.md)

## 1. 目的と課題
本計画は、出荷明細自動集計システム（`run_automation.py`）の堅牢性を高め、非エンジニアのユーザーが誤操作（ファイルの開きっぱなし、CSV名の誤り、配置ミスなど）をした際にも安全に終了し、かつ自力で解決できる具体的なエラーメッセージとマニュアル（`README.md`）を提供することを目的とします。

また、既存の脆弱性レポート（`adversarial_review_report.md`）で指摘されている以下の重大な脆弱性が解消されていることを担保します：
1. Excelプロセスの解放漏れ・ゾンビプロセスの残留
2. エラーログ出力先の個人フォルダパスのハードコーディング
3. CSVデータの列位置インデックスのハードコーディング
4. 1セルずつの書き込み処理による極端なパフォーマンスボトルネック

## 2. 現状と修正方針

### ① 異常系の挙動改善（R1）
- **Excelファイルが開いたままの実行**: `RETAIL_完成版.xlsx` を開いたまま実行すると、`openpyxl` が書き込み・保存時に `PermissionError` を起こします。このエラーをキャッチし、「RETAIL_完成版.xlsx を開いたまま実行しています。Excelを閉じてから再実行してください。」といった、非エンジニアでも直感的に理解できるエラーメッセージを表示するように改善します。
- **指定外のファイル名 / CSV不足**: 読み込み対象のCSVが見つからない、または複数見つかった場合に、`run_automation.py` は現在 `sys.exit(1)` を呼んで終了していますが、非エンジニアには黒い画面が消えるだけで何が起きたか分かりません。GUIメッセージボックスでエラーを表示し、`error.log` にも同じエラーを分かりやすい日本語で記録します。

### ② 既存脆弱性の解消担保（R3）
- **Excelプロセス/リソースの解放漏れ**: 現在の `run_automation.py` は `openpyxl` を使用しており、`win32com` による Excel.exe ゾンビプロセスの残留は本来発生しません。ただし、`openpyxl` の `Workbook.close()` を `finally` 句で確実に呼び出し、ファイルロック等のリソースリークを防ぎます。
- **個人フォルダへのハードコーディング**: `ERROR_LOG_PATH` などのパスは、動的解決（`BASE_DIR` 基準）されていることを確認・維持します。
- **CSV列位置インデックスのハードコーディング**: 既存コードは列名によるフィルタリング（例: `df["表記部門名1"]` など）を採用しており、ある程度インデックスへの依存は排除されていますが、再度コードを確認し、脆弱性がないかをチェックします。
- **1セルずつの書き込み処理のボトルネック**: 現行の `step1_create_retail_wb` 等で2重ループによるセル個別書き込みを行っています。データ量が多い場合、処理が非常に遅くなるため、必要に応じて一括書き込みに修正します。

### ③ エラーメッセージとマニュアル（README.md）の完全同期（R2）
- スクリプトが画面に表示する、あるいは `error.log` に出力するエラーメッセージの文言と、`README.md` のトラブルシューティング（対処法）を100%一致させます。
- 「Permission Error」「IndexError」「FileNotFound」などのIT専門用語を排除し、以下のように翻訳した表現を使用します。
  - `PermissionError` → 「ファイルが開いたままです（アクセスが拒否されました）」
  - `FileNotFoundError` (CSV不足) → 「必要なCSVファイルが見つかりません」
  - テンプレート不足 → 「★RETAIL_テンプレート.xlsx が見つかりません」

## 3. テスト計画

### テストケース一覧

| テストケースID | 対象の異常状態 | 期待される挙動 |
| :--- | :--- | :--- |
| **TC-01** | `RETAIL_完成版.xlsx` を Excel で開いたまま実行 | ポップアップまたはエラー表示で「RETAIL_完成版.xlsx を閉じてから再実行してください」と表示され、安全に終了する。`error.log` にもその旨が日本語で記録される。 |
| **TC-02** | 必須CSVファイルが不足（例: `卸売上明細.csv` が `input/` にない） | 「卸売上明細.csv が input フォルダに見つかりません」と表示され、プログラムが安全に終了する。 |
| **TC-03** | CSVファイル名が指定外（例: `卸売上明細 (2).csv` など、重複または名前間違い） | 「input フォルダに該当するCSVが見つかりません」または「同種のCSVが複数あります」という具体的なメッセージが表示されて安全に終了する。 |
| **TC-04** | テンプレートファイル `★RETAIL_テンプレート.xlsx` が存在しない | 「テンプレートファイルが見つかりません」と表示され、安全に終了する。 |

## 4. 実行手順とサブエージェント体制
- **Orchestrator** (本エージェント): 計画・進捗管理・指示
- **Explorer (explorer_1)**: 実機環境の調査とテスト実行、エラー再現、問題点分析
- **Worker (worker_1)**: スクリプト (`run_automation.py`) およびマニュアル (`README.md`) の修正、およびテスト
- **Reviewer (reviewer_1)**: 修正後のコードのレビュー、脆弱性の再評価、READMEの同期確認
