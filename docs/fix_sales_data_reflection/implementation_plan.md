# 実装計画書 (Implementation Plan) - 売上あり商品の自動行追加

## 概要
出荷予定データ（`出荷予定振分.csv`）に存在しない商品であっても、各売上CSV（ZOZO、OIOI、店舗売上、EC受注）に売上実績がある場合は、自動的に `order` シートおよび `RETAIL` シートの末尾に行を追加して売上を反映させるようにロジックを拡張します。

---

## 🛠️ 提案する変更内容

### 1. 売上発生商品の抽出とマスタ逆引き
* 各売上データ（ZOZO、OIOI、店舗、EC）の集計後、売上数が 1 以上の商品コード（SHORT）のうち、今回の `出荷予定振分.csv` に存在しない商品（漏れ商品）をリストアップします。
* `商品マスタ全項目.csv` を検索し、漏れ商品の「商品名」および「LONGコード」を取得します。
  * マスタに登録されていない商品（北欧展グッズなど）は、売上CSV内の商品名を使用し、SHORTコードをそのまま商品コードとして使用します。

### 2. order シートへの動的行追加
* `order` シートの末尾（`lastRow + 1` 以降）に漏れ商品分の行を新規追加します。
  * **A列（商品コード）**: LONGコード（なければSHORTコード）
  * **B列（商品名）**: 商品名
  * **C〜Q列（BULK）**: すべて 0 または空
  * **R〜AD列（在庫）**: すべて 0 または空
  * **AE〜AQ列（ORDER）**: 集計された売上実績数を書き込む（売上がないセルは 0）
  * **AR〜BG列（過不足・合計計算式）**: 通常商品と同様に、自シート内計算を行う数式（`=E{r}-AE{r}` 等）を動的に書き込みます。

### 3. RETAIL シートへの動的行追加と連携
* `RETAIL` シートの末尾（`lastRowRetail + 1` 以降）にも同様に行を追加します。
  * **D列（商品コード）**: LONGコード（なければSHORTコード）
  * **E列（商品名）**: 商品名
  * **F列（Brand）**: "FRV"
  * **AW〜BY列（出荷指示・出荷予定数）**: `order` シートの追加行を参照する数式（`=order!AE{r_order}` 等）を書き込み、両シートの数値を完全に同期させます。

### 4. 集計・書式範囲の自動拡張
* 1行目の `SUBTOTAL` 計算式や、条件付き書式、オートフィルター、および罫線の適用範囲を、追加された最終行（`lastRow + 漏れ商品数`）まで自動的に拡張します。

## 📋 検証計画

### 1. 自動テスト（verify_all.py による検証）
* プログラム実行後、自動検証スクリプト `verify_all.py` を実行します。
* 今回は漏れ商品もすべて末尾に自動追加されるため、**すべての店舗・チャネル（ZOZO、OIOI、EC、名古屋、TOKYO、ヒュッテなど）の合計値が正誤表と100%完全一致（[OK]）すること**を確認します。

### 2. Excelでの目視確認
* 出力された `RETAIL_完成版.xlsx` を開き、末尾に「Singi Merino Henley M」や「Abisko Summer Hat」などの行が正しく追加されていること、および `RETAIL` シートの追加行に数式が入っていることを確認します。
