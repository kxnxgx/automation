# 実装計画 - Milestone 4 (調査・検証)

## 概要
本計画は、出荷集計システムが本番データにおいて正しく動作し、すべての数値が一致するかを検証するための手順を定めます。

## 検証手順
1. **入力データの確認**
   * `C:\Users\kxnxg\OneDrive\デスクトップ\automation\input` フォルダ配下に存在するCSVファイルをリストアップし、集計対象のファイルを特定します。
2. **検証バッチの実行**
   * 環境変数 `NO_GUI=1` を設定した上で、`C:\Users\kxnxg\OneDrive\デスクトップ\automation\実行.bat` を実行します。
   * バッチファイルの末尾にある `pause` によるハングアップを防ぐため、標準入力に改行を渡す形式で実行します。
3. **出力ログの照合**
   * 実行ログに `[OK] すべて一致しています！` というメッセージが含まれており、処理が正常終了（Exit code: 0）していることを確認します。
4. **報告資料の作成**
   * 実行結果および入力CSVファイルの一覧を `handoff.md` に記録します。
   * プロジェクトオーケストレーターに完了を通知します。
