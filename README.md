# 【取扱説明書】出荷明細・売上集計の自動作成プログラム

このプログラムは、日々ダウンロードする各種CSVファイル（売上や出荷予定のデータ）を自動でまとめ、集計表（Excelファイル）を作成するものです。
手作業でのコピペや集計の作業を行うことなく、ボタンをダブルクリックするだけで正確な集計表が完成します。

---

## 1. 準備：データを「input」フォルダに保存する

プログラムを実行する前に、システム等から以下の **8つのファイル（CSVおよびExcel）** をダウンロード等で用意し、同じ場所にある `input` フォルダの中に保存してください。

| 保存するファイルの名前（キーワード） | 対象データ | ダウンロード方法・備考 |
| :--- | :--- | :--- |
| **出荷予定振分\*.csv**<br>（例：`出荷予定振分.csv`） | 出荷予定のベースデータ | 出荷管理システムから出力される出荷予定の基礎データです。ファイル名に「出荷予定振分」という文字が含まれていれば大丈夫です。 |
| **営業日付別売上分析\*.csv**<br>（例：`営業日付別売上分析.csv`） | 直営店舗の売上実績 | 店舗売上システムから出力される、直営店別の売上データです。ファイル名に「営業日付別売上分析」という文字が含まれていれば大丈夫です。 |
| **卸売上明細.csv** | ZOZOの売上実績 | ZOZO管理画面から出力される売上明細データです。ファイル名は必ず `卸売上明細.csv` としてください。 |
| **卸売上明細 (1).csv** | OIOI（丸井）の売上実績 | 丸井（OIOI）の管理画面から出力される売上明細データです。ファイル名は必ず `卸売上明細 (1).csv` としてください。 |
| **order_\*.csv**<br>（例：`order_20260705.csv`） | 自社ECの受注実績 | 自社ECシステムから出力される受注明細データです。ファイル名が `order_` から始まるCSVを保存してください。 |
| **★出荷指示フォーマット【*】hutte.xlsx**<br>（例：`★出荷指示フォーマット【20260705】hutte.xlsx`） | HUTTEの出荷指示データ | HUTTE用の出荷指示データです。「★出荷指示フォーマット」と「hutte」が含まれるファイル名のExcelファイルが対象です。自動で最新のファイルが読み込まれます。 |
| **商品マスタ-ZOZO-OlOl.xlsx** | ZOZO・OIOIマスタ | ZOZOとOIOIの登録状況が記載されたマスタデータです。ファイル名は必ずこの通りにしてください。 |
| **2026特価在庫.xlsx** | 特価在庫マスタ | 特価商品の一覧データです。ファイル名は必ずこの通りにしてください。 |

> 💡 **注意点**
> - `input` フォルダの中には、上記以外の不要なファイルが入っていない状態にしてください。前の日付の古いファイルが残っていると、誤ってそちらを集計してしまう原因になります。
> - 今回のアップデートで、`order` シートの右側（BH列〜BM列）に、HUTTE・ZOZO・OIOI・特価の各入力ファイルからデータが自動的に抽出・転記される機能が追加されました。手作業でのVLOOKUPは不要になります。

---

## 2. 実行手順

1. `input` フォルダに必要な5つのファイルがすべて揃っていることを確認します。
2. 作成されるファイルである `RETAIL_完成版.xlsx` が、すでに別のExcel画面で開かれていないことを確認します（開いている場合は、必ず閉じておいてください）。
3. フォルダ内にある **`実行.bat`** というファイルを **ダブルクリック** します。
4. 黒い画面（コマンド画面）が開き、プログラムが自動的にデータの集計と検証を開始します。

---

## 3. 結果の確認方法

### ① 黒い画面（コマンド画面）での確認
プログラムの集計が終わると、黒い画面にCSVの合計値とExcelの合計値の突き合わせ結果が表示されます。
画面の最後に、以下のメッセージが表示されていることを確認してください。

```text
[OK] すべて一致しています！
```

このメッセージが表示されていれば、データの集計が1件のズレもなく完璧に行われた証拠です。
確認ができたら、キーボードの「Enter」などのキーを押して黒い画面を閉じてください。

### ② 完成した集計表の確認
プログラムと同じフォルダに **`RETAIL_完成版.xlsx`** というExcelファイルが作成（または上書き）されます。
これを開いて、集計データが正しく反映されていることを確認してください。

## 4. うまく動かないときの対処法（トラブルシューティング）

プログラムの実行中にエラーが発生した場合は、画面に表示されるメッセージ、またはプログラムと同じフォルダに作成される **`error.log`** ファイルの内容（詳細なエラー原因）を確認してください。

以下は、発生する代表的なエラーメッセージと対処方法です。

### Q1. 「完成版Excelファイルが開いたままです」と表示される
* **状況**: 完成版Excel（`RETAIL_完成版.xlsx`）がExcelなどのアプリケーションで開かれた状態になっています。
* **対処方法**: 開いている `RETAIL_完成版.xlsx` を閉じてから、もう一度実行してください。

### Q2. 「必要なCSVファイルが見つかりません」と表示される
* **状況**: `input` フォルダの中に、対象となるCSVファイルが見つかりません。
* **対処方法**: `input` フォルダの中に、上記「1. 準備」で説明した通りの名前でCSVファイルが正しく保存されているか再確認してください。特に、ファイルの名前（キーワード）や半角・全角のスペース、カッコの形（ `(1)` ）などが間違っていないか注意してください。

### Q3. 「同じ種類のCSVファイルが複数あります」と表示される
* **状況**: `input` フォルダの中に、同じ種類のCSVファイルが複数保存されています（例：古い日付の売上CSVが残っているなど）。
* **対処方法**: 処理対象にしたい最新のCSVファイル1つだけを `input` フォルダに残し、不要な古いCSVファイルは別の場所に移動させるか削除した上で、もう一度実行してください。

### Q4. 「プログラム実行中にエラーが発生しました」と表示される
* **状況**: プログラムの実行中に、その他の予期しないエラーが発生しました。
* **対処方法**: 同じフォルダに新しく作成された **`error.log`** というファイルをダブルクリックして開き、その内容をシステム管理者または開発者に提供して調査を依頼してください。

### Q5. 集計された数値が異常に大きい（数千件などになる）
* **状況**: システムのエラーではなく、ダウンロードしたCSVファイル（特に `order_*.csv` など）の中に、「過去1年分」や「全期間」のデータが含まれてしまっていることが原因です。
* **対処方法**: EC管理画面や売上管理システムに戻り、CSVをダウンロードする際の**「期間指定（出力対象の日付）」**が正しく1日分になっているか確認して再ダウンロードしてください。その後、`input` フォルダ内の間違ったファイルを削除し、新しいファイルだけを入れて再実行してください。
