# 【取扱説明書】出荷明細・売上集計の自動作成プログラム

このプログラムは、日々ダウンロードする各種CSVファイル（売上や出荷予定のデータ）を自動でまとめ、ブランドごと（FRV, tennen, HANWAG）の集計表（Excelファイル）を作成するものです。
手作業でのコピペや集計の作業を行うことなく、**`実行.bat` をダブルクリックするだけ**で3ブランド分すべての集計表が完成します。

---

## 1. システム構成とファイル構成

本システムは、主要な集計・マージおよび数値検証のコアロジックを共通モジュール（`automation_core.py`）に集約し、各ブランドごとの実行用スクリプトからそれを呼び出す構造になっています。

### ディレクトリ構成図
```text
c:\Users\kesuzuki\Desktop\出荷表自動化\
├── input/                    # 【全ブランド共通】入力データフォルダ（CSVや指示書をここに置く）
├── output/                   # 【自動作成】完成した各ブランドのExcelファイルが保存されます
├── archive/                  # 【自動作成】処理が正常完了した際、過去のinputデータが日時別でここに移動されます
├── docs/
│   └── REVIEW_REPORT.md      # レビュー結果報告書（開発・改修時の参考資料）
├── automation_core.py        # 【共通】集計・マージ・検証ロジックを集約した共通モジュール
├── run_automation.py         # FRV用の自動化実行スクリプト
├── run_automation_tennen.py  # tennen用の自動化実行スクリプト
├── run_automation_hanwag.py  # HANWAG用の自動化実行スクリプト
├── verify_all.py             # FRV用のデータ検証スクリプト
├── verify_all_tennen.py      # tennen用のデータ検証スクリプト
├── verify_all_hanwag.py      # HANWAG用のデータ検証スクリプト
├── debug_diff.py             # 差異デバッグ用スクリプト（ブランド切り替え対応）
├── 実行.bat                  # 【メイン】3ブランドを一括実行するバッチファイル（正常終了で自動アーカイブ）
├── 実行_FRV.bat              # FRVのみ実行するバッチファイル
├── 実行_tennen.bat           # tennenのみ実行するバッチファイル
├── 実行_hanwag.bat           # HANWAGのみ実行するバッチファイル
└── ★RETAIL_テンプレート.xlsx  # 店舗ヘッダー等のデザインが定義されたマスタテンプレート
```

## 2. 準備：データを「input」フォルダに保存する

**FRV・tennen・HANWAG 3ブランド分のデータをすべてまとめて** `input` フォルダに保存してください。ブランドを分けて置く必要はありません。

### 保存するファイル一覧

| 保存するファイルの名前（キーワード） | 対象データ | ダウンロード方法・備考 |
| :--- | :--- | :--- |
| **出荷予定振分\*.csv**<br>（例：`出荷予定振分.csv`） | 出荷予定のベースデータ | **※全ブランドが混在したデータのままで問題ありません！**<br>プログラムが自動的に各ブランドのデータだけを抽出します。 |
| **営業日付別売上分析\*.csv**<br>（例：`営業日付別売上分析.csv`） | 直営店舗の売上実績 | 店舗売上システムから出力されるデータ。 |
| **卸売上明細.csv** | ZOZOの売上実績 | ファイル名は必ず `卸売上明細.csv` としてください。 |
| **卸売上明細 (1).csv** | OIOI（丸井）の売上実績 | ファイル名は必ず `卸売上明細 (1).csv` としてください。 |
| **order_\*.csv**<br>（例：`order_20260705.csv`） | 自社ECの受注実績 | ファイル名が `order_` から始まるCSV。 |
| **★出荷指示フォーマット【*】hutte.xlsx** | HUTTEの出荷指示データ | 自動で最新ファイルが読み込まれます。 |
| **商品マスタ-ZOZO-OlOl.xlsx** | ZOZO・OIOIマスタ | ※必要な場合のみ入れてください。 |
| **2026特価在庫.xlsx** | 特価在庫マスタ | ※必要な場合のみ入れてください。 |

> 💡 **自動化システムの便利機能と注意点**
> - **マイナス数値（返品分）の自動削除**: 注文のキャンセルや返品などで数値がマイナス（-1など）になっているデータは、集計時に自動的に「0」として処理されます。
> - **在庫不足時の自動ゼロ化**: 在庫確保枠が全売上合計を下回る場合、ZOZO・OIOI・EC・YSEC・店舗すべてのチャネルの売上が自動的に0に設定されます（誤発注防止）。
> - **データの自動アーカイブ**: `実行.bat`（3ブランド一括）が正常に完了すると、`input` フォルダ内のファイルは `archive` フォルダ内の日時フォルダへ自動で移動し、`input` フォルダは空になります。※個別のバッチファイル実行時はアーカイブされません。

## 3. 実行手順

1. `input` フォルダに必要なファイルがすべて揃っていることを確認します。
2. 出力先のExcelファイルが、すでに別のExcel画面で開かれていないことを確認します。
3. フォルダ内にある **`実行.bat`** を **ダブルクリック** します。
   * FRV → tennen → HANWAG の順に自動で3ブランド分すべて作成されます。
   * 特定のブランドだけ作成したい場合は、個別のバッチファイルも利用できます：
     * FRVのみ: **`実行_FRV.bat`**
     * tennenのみ: **`実行_tennen.bat`**
     * HANWAGのみ: **`実行_hanwag.bat`**
4. 黒い画面（コマンド画面）が開き、プログラムが自動的にデータの集計と検証を開始します。

> ⚠️ **注意**: `実行.bat` で全ブランド一括実行する場合、1ブランドでエラーが発生すると以降のブランドの処理は中断されます。エラーが出た場合は個別のバッチファイルで原因を特定してください。

---

## 4. 結果の確認方法

### ① 黒い画面（コマンド画面）での確認
プログラムの集計が終わると、黒い画面にCSVの合計値とExcelの合計値の突き合わせ結果が表示されます。
各ブランドの処理が完了するたびに、以下のメッセージが表示されていることを確認してください。

```text
[OK] すべて一致しています！
```

このメッセージが表示されていれば、データの集計が1件のズレもなく完璧に行われた証拠です。

### ② 完成した集計表の確認
プログラムの `output` フォルダ内に、今日の日付が入った **ブランド別のExcelファイル** が3つ作成されます。

* 例：**`output\20260706 RETAIL FRV.xlsx`**
* 例：**`output\20260706 RETAIL TEN.xlsx`**
* 例：**`output\20260706 RETAIL HWG.xlsx`**

これを開いて、集計データが正しく反映されていることを確認してください。

## 5. 差異デバッグ（突き合わせ検証）スクリプトの使い方

売上データの不一致や集計ミスが発生した際の調査のため、`debug_diff.py` が用意されています。

### 実行方法
コマンドプロンプトやPowerShellから、引数に対象のブランド名を指定して実行します。

```bash
# FRV のデバッグを実行 (引数を省略した場合はデフォルトで FRV になります)
python debug_diff.py FRV

# tennen (TEN) のデバッグを実行
python debug_diff.py TEN

# HANWAG (HWG) のデバッグを実行
python debug_diff.py HWG
```

### スクリプトの特長
- **商品レベル（セル単位）の網羅的検証**: 商品コードごと、かつ13チャネル（ZOZO, OIOI, EC, 直営10店舗）ごとにCSVの期待値とExcel上の実際値をセル単位で照合します。
- **差異レポートの自動出力**: 期待値と実際値が異なるセルが検出された場合、該当行番号・商品コード・チャネル名・期待値・実際値を詳細リストとして出力します。
- **前提データチェック**: Excelシート内に数式エラー（`#REF!` や `#VALUE!` など）が含まれている場合、処理の前に検出し、警告を行います。

## 6. うまく動かないときの対処法（トラブルシューティング）

プログラムの実行中にエラーが発生した場合は、画面に表示されるメッセージ、またはプログラムと同じフォルダに作成される **`error.log`** ファイルの内容（詳細なエラー原因）を確認してください。

### Q1. 「完成版Excelファイルが開いたままです」と表示される
* **状況**: 出力先となるExcelファイルがExcelなどのアプリケーションで開かれた状態になっています。
* **対処方法**: 開いているExcelファイルを閉じてから、もう一度バッチファイルを実行してください。

### Q2. 「必要なCSVファイルが見つかりません」と表示される
* **状況**: `input` フォルダの中に、対象となるCSVファイルが見つかりません。
* **対処方法**: `input` フォルダの中に、上記「2. 準備」で説明した通りの名前でCSVファイルが正しく保存されているか再確認してください。

### Q3. 「同じ種類のCSVファイルが複数あります」と表示される
* **状況**: `input` フォルダの中に、同じ種類のCSVファイルが複数保存されています（例：古い日付の売上CSVが残っているなど）。
* **対処方法**: 処理対象にしたい最新のCSVファイル1つだけを残し、不要な古いCSVファイルは削除した上でもう一度実行してください。

### Q4. 「プログラム実行中にエラーが発生しました」と表示される
* **状況**: プログラムの実行中に、その他の予期しないエラーが発生しました。
* **対処方法**: 同じフォルダに新しく作成された **`error.log`** というファイルをダブルクリックして開き、その内容をシステム管理者または開発者に提供して調査を依頼してください。

### Q5. 集計された数値が異常に大きい（数千件などになる）
* **状況**: ダウンロードしたCSVファイルの中に、「過去1年分」や「全期間」のデータが含まれてしまっていることが原因です。
* **対処方法**: 各種管理システムに戻り、CSVをダウンロードする際の**「期間指定（出力対象の日付）」**が正しく1日分になっているか確認して再ダウンロードしてください。

### Q6. `実行.bat` の途中でブランドの処理が止まった
* **状況**: いずれかのブランドでエラーが発生し、以降のブランドの処理が中断されています。
* **対処方法**: エラーメッセージを確認し、問題を解決後、個別のバッチファイル（`実行_FRV.bat` など）で残りのブランドを実行してください。
