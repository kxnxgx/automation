* **検証内容**: 改修後のプログラムを実行し、出力された `RETAIL_完成版.xlsx` が元の各CSVファイルの合計値と完全に一致することを確認します。
* **検証手順**:
  1. `input` フォルダに正常な5つのCSVファイルが配置されていることを確認します。
  2. プログラムを実行し、正常終了することを確認します。
  3. `verify_all.py` を実行し、画面の最後に `[OK] すべて一致しています！` と表示されることを確認します。
* **期待される結果**:

## 2. 異常系検証 (エラーハンドリングとユーザー案内)
### ① 必須CSVファイルの欠損
* **検証内容**: 必要なCSVファイルが不足している際に、適切な日本語メッセージダイアログが表示され、`error.log` にスタックトレースが書き出されることを確認します。
* **検証手順**:
  1. `input` フォルダから `出荷予定振分.csv` を一時的に退避させます。
  2. プログラムを実行します。
  3. エラーダイアログが開き、以下の日本語メッセージが表示されることを確認します。
     * **タイトル**: `必要なCSVファイルが見つかりません`
     * **メッセージ**: `【発生した状況】\n「input」フォルダの中に「出荷予定振分」を含むCSVファイルが見つかりません。\n\n【対処方法】\n指定されたCSVファイルを「input」フォルダ内に保存してから、もう一度実行してください。`
  4. プログラム直下に `error.log` が作成され、冒頭に上記のエラーメッセージ、その後に詳細なスタックトレースが記録され、プログラムが安全に終了することを確認します。

### ② 重複CSVファイルの存在
* **検証内容**: 同じ種類のCSVファイルが複数存在する際に、エラーダイアログと `error.log` に適切に情報が出力されることを確認します。
* **検証手順**:
  1. `input` フォルダ内に `出荷予定振分.csv` のコピー（`出荷予定振分 - コピー.csv`）を作成します。
  2. プログラムを実行します。
  3. エラーダイアログが開き、以下の日本語メッセージが表示されることを確認します。
     * **タイトル**: `同じ種類のCSVファイルが複数あります`
     * **メッセージ**: `【発生した状況】\n「input」フォルダの中に「出荷予定振分」に該当するCSVファイルが複数見つかりました。\n\n見つかったファイル:\n・出荷予定振分.csv\n・出荷予定振分 - コピー.csv\n\n【対処方法】\n不要な古いCSVファイルを「input」フォルダから移動または削除して、1つだけにしてからもう一度実行してください。`
  4. `error.log` に上記メッセージと詳細なトレースバックが記録されていることを確認します。

### ③ 完成版Excel（RETAIL_完成版.xlsx）の開きっぱなし
* **検証内容**: 完成版Excelが開かれた状態でプログラムを実行した際、`PermissionError` を安全にキャッチして分かりやすいメッセージが表示されることを確認します。
* **検証手順**:
  1. `RETAIL_完成版.xlsx` を手動でExcelで開いておきます。
  2. プログラムを実行します。
  3. 保存処理で `PermissionError` が発生し、以下のエラーダイアログが表示されることを確認します。
     * **タイトル**: `完成版Excelファイルが開いたままです`
     * **メッセージ**: `【発生した状況】\n完成版Excel（RETAIL_完成版.xlsx）がExcelなどのアプリケーションで開かれた状態になっています。\n\n【対処方法】\n開いている「RETAIL_完成版.xlsx」のExcel画面を完全に閉じてから、もう一度実行してください。`
  4. `error.log` に上記メッセージと詳細なトレースバックが記録されていることを確認します。
